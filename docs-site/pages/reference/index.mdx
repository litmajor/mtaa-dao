## Regenerating

```bash
node docs-site/scripts/generate-reference.mjs
```

The generator walks `server/index.ts` and `server/routes.ts`, follows every
`app.use`/`router.use` mount, then scans `shared/*.ts` for Drizzle tables and
`contracts/**/*.sol` for Solidity declarations.

## Status labels used across the docs

| Label | Meaning |
| --- | --- |
| `IMPLEMENTED` | Present in the current code and traceable to a source file |
| `PARTIALLY IMPLEMENTED` | Present but gated, stubbed, or only partly wired |
| `DEPRECATED` | Still present but redirecting, sunset-flagged, or returning `410` |
| `PLANNED` | Described in the repository but with no implementation found |
| `UNVERIFIED` | Documented previously; not confirmed against the code in this pass |
