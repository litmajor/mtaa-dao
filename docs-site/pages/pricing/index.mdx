## Transaction Fees Explained

### Platform Fee (Pay-as-you-go)

We charge a small percentage of each transaction to cover:
- Blockchain gas fees
- Server infrastructure
- AI model costs
- Development & support
- Security audits

| Tier | Platform Fee |
|------|--------------|
| Free | 3.0% |
| Short-Term | 2.5% |
| Collective | 2.5% |
| MetaDAO | 2.0% |

**Example:**
```
Member contributes ₭1,000:
- Free Tier: ₭30 fee → ₭970 to treasury
- Paid Tier: ₭25 fee → ₭975 to treasury

Member withdraws ₭5,000:
- Free Tier: ₭150 fee → Receives ₭4,850
- Paid Tier: ₭125 fee → Receives ₭4,875
```

### Payment Method Fees

**M-Pesa:**
- Contributions: Standard M-Pesa charges apply (~₭10-₭100 depending on amount)
- Withdrawals: Standard M-Pesa B2C charges
- **MtaaDAO doesn't add extra fees on top of M-Pesa**

**Bank Transfer:**
- Pesalink: Usually free
- EFT: May have bank charges (₭50-₭100)
- RTGS: ₭200-₭500 (for large amounts)

**Crypto Wallet:**
- Celo: ~₭5-₭15 gas fee
- Polygon: ~₭1-₭5 gas fee
- Ethereum L2s: ~₭10-₭30 gas fee

## Upgrade & Downgrade

### Upgrading

**From Free → Short-Term:**
```
1. Click "Upgrade DAO" in settings
2. Choose duration (30/60/90 days)
3. Pay ₭500-₭1,000 via M-Pesa
4. Instant activation
5. All data, members, funds transfer automatically
```

**From Free → Collective:**
```
1. Click "Upgrade to Collective"
2. Pay ₭1,500 (first month)
3. Set up recurring payment (monthly or annual)
4. Instant unlimited access
```

**From Short-Term → Collective:**
```
1. Extend before expiry OR after expiry
2. Pay ₭1,000 (difference for first month)
3. Then ₭1,500/month recurring
4. No data loss, seamless transition
```

### Downgrading

**From Collective → Short-Term:**
```
Requirements:
- Give 30-day notice
- Cannot downgrade mid-month
- Next billing cycle converts to Short-Term

Note: Lose MetaDAO access, advanced features
```

**From Collective → Free:**
```
Requirements:
- Reduce members to ≤10
- Reduce treasury to ≤₭50K
- Request downgrade via support
- 48-hour processing time

Warning: Significant feature loss
```

## Frequently Asked Questions

### What if I can't afford ₭1,500/month?

**Options:**
1. **Start with Free Tier** (₭0) - Test with small group first
2. **Use Short-Term** (₭500 one-time) - For temporary needs
3. **Share costs** - ₭1,500 ÷ 50 members = ₭30/member
4. **Start small, grow later** - Begin with Free, upgrade when treasury grows

### Can I pause my subscription?

**Short-Term:** No refunds, but can transfer to another DAO
**Collective:** 
- Can cancel anytime (stops at end of current month)
- Can pause for up to 3 months (₭500 pause fee)
- Reactivation: Pay current month to resume

### Do you offer discounts?

**Yes! Discounts for:**
- Annual payment: 2 months free (17% off)
- Educational institutions: 25% off
- Non-profits: 30% off
- MetaDAOs (bulk): Custom pricing
- Early adopters: Grandfathered rates

**Apply for discount:** support@mtaadao.com

### What happens if I don't pay?

**Day 1-7:** Reminder emails/SMS  
**Day 8:** DAO enters "grace mode" (read-only, no new transactions)  
**Day 15:** DAO suspended (no access)  
**Day 30:** DAO archived (can reactivate within 90 days)  
**Day 120:** Permanent deletion (treasury returned to members)

**To reactivate:** Pay all outstanding fees + ₭500 reactivation fee

### Are there hidden fees?

**NO hidden fees. Ever.**

You pay:
1. DAO tier subscription (₭0-₭1,500/month)
2. Transaction fees (2.5-3%)
3. Your payment method's standard fees (M-Pesa, bank, crypto gas)

That's it. We hate hidden fees as much as you do.
